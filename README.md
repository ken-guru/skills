## Repository structure

- `skills/<name>/SKILL.md` is a Standalone Skill.
- `skills/<suite>/<name>/SKILL.md` is a Skill Suite member.
- A suite root contains `README.md` and no `SKILL.md`.
- Skill nesting stops at one suite level.
