The final answer is a Source Set for the pair-programming question. Check each claim:

1. It lists at least three distinct sources, each with enough reference detail (author or publisher, date or year, and a title or URL) for a person to find it.
2. Each source has its own credibility judgement that names a reason to trust it and a caveat (for example sample size, age, or who funded it).
3. Each source lists the specific claims it supports, not just a topic.
4. Where the sources disagree or differ in strength, the answer says so, or asks the person how to handle it, rather than presenting one blended conclusion.
5. It asks the person to approve the Source Set, or says it is awaiting approval.

Score 1 only if all five hold.
