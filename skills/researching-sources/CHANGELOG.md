# Changelog

## 1.0.0

- First release. Agrees the question and scale, reads supplied sources, searches for what is missing, judges credibility, puts conflicts to the person as questions with a recommended ruling, and writes an approved Source Set.
- Treats fetched content as data, never instructions, and records an explicit waiver instead of skipping research silently.
- Eval cases for a start with no sources, conflicting sources, a prompt-injection page, writing to a file, and a request that should not trigger the skill.
